### 🚀 What I'm Building

**C-Flux** — *An AI-Powered Document Assistant (In Progress)*
* Architecting a decoupled, event-driven backend separating stateless REST APIs from a stateful WebSocket server.
* Engineering a production-grade Retrieval-Augmented Generation (RAG) pipeline using **Google Gemini** for 3072-dimensional text embeddings and **Pinecone** for semantic vector search.
* Building an asynchronous ingestion worker using a **Redis Message Queue** to parse PDFs and handle API rate limits gracefully.
* Scaling real-time AI responses horizontally by implementing a **Redis Pub/Sub** architecture to route streaming response chunks to specific concurrent users.

**[CoreWire](https://corewire.vercel.app/)** — *A Real-Time Multiplayer Code Workspace*
* Engineered a browser-based IDE using native WebSockets for sub-millisecond code syncing and live team chat with persistent rooms across multiple clients.
* Fixed the infamous "ping-pong" infinite broadcast bug by building a custom React `useRef` architecture to intercept Monaco Editor updates.
* Integrated JDoodle Compiler API for secure, live Node.js code execution in the cloud.
* Locked socket connections to authenticated user IDs to prevent chat spoofing and handle "late-joiner" syncing.
* Implemented an auto-save feature using a custom debounce hook to drastically reduce database write operations.

**[Tunesta](https://tunesta.netlify.app/)** — *A Cloud-Native Personal Music Library*
* Built a media vault with persistent cloud storage (Cloudinary) and secure JWT Identity Management for complete user data isolation.
